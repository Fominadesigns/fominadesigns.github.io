# Fomina.Designs

Сайт-портфоліо. Статика: HTML + CSS + трохи JavaScript, без збірки й залежностей.

## Структура

```
index.html                 головна сторінка
chi-vtrachaie-...html      квіз (стара збірка Webflow)
css/style.css              стилі головної
css/*.webflow.css          стилі квіза
js/app.js                  меню, поява блоків, прев'ю кейсів
images/cases/              скріншоти сайтів для прев'ю на ховері
```

## Шрифти

Усі — безкоштовні для комерційного використання, підключені з Google Fonts:

- **Geologica** — заголовки
- **Wix Madefor Display** — текст
- **Cormorant Italic** — акцентні слова
- **JetBrains Mono** — мікропідписи

## Що потребує уваги

- ціни в секції «Ціни» і терміни в секції «Процес» — орієнтовні, підтвердити
- `images/about.jpg` — фото для блоку «Про мене», поки заглушка
- кейс «Темп Дніпра» веде на версію в GitHub Pages; замінити на `tempdnipra.pp.ua`, коли домен запрацює

## Локальний запуск

```
npx serve
```
